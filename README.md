# Convertisseur de fichiers

Ce site web permet de **convertir facilement différents types de fichiers directement depuis le navigateur**.

Il prend en charge les images, les PDF, les documents Word, les fichiers Excel, les fichiers texte, ainsi que les fichiers audio et vidéo.

**Fonctionnalités :**
- Conversion de plusieurs fichiers en une seule fois.
- Ajout de fichiers par glisser-déposer.
- Conversion vers différents formats.
- Suivi de la progression des conversions.
- Téléchargement des fichiers convertis.

Les conversions sont réalisées directement dans le navigateur, sans nécessiter l'installation d'un logiciel.
